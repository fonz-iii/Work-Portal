# assets/images/

Pictures for the Home page. File names are set in `data/home.js`:

| File | Where it shows | Suggested size |
|---|---|---|
| `placeholder-1.jpg` … `placeholder-5.jpg` | Main picture slide show (top of Home; one line per picture in `heroSlides`) and, for now, the Highlights row | any shape; about 1200 × 800 px is best |
| `home-hero.jpg` | Single main picture, used only when `heroSlides` is empty | 1200 × 800 px |

The `placeholder-*.jpg` pictures are stand-ins. Replace them (same names) or point `data/home.js` at your own files. Missing files show a grey placeholder that names the file to add. Do not use pictures containing customer or confidential information.
