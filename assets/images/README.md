# assets/images/

Pictures for the Home page. Drop files here with these names (or change the names in `data/home.js`):

| File | Where it shows | Suggested size |
|---|---|---|
| `home-hero.jpg` | Main picture, top of Home | 1200 × 800 px |
| `home-feature-1.jpg` … `home-feature-3.jpg` | Highlights row | 800 × 500 px |

Missing files show a grey placeholder that names the file to add. Do not use pictures containing customer or confidential information.
