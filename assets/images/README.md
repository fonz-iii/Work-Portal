# assets/images/

Pictures for the Home page. File names are set in `data/home.js`:

| File | Where it shows | Suggested size |
|---|---|---|
| `team-1.jpg` … `team-3.jpg` | Main picture slide show (top of Home; one line per picture in `heroSlides`) and the Highlights row | any shape; about 1200 × 800 px is best |
| `home-hero.jpg` | Single main picture, used only when `heroSlides` is empty | 1200 × 800 px |

The `team-*.jpg` pictures are the Marketing Group's own photos (resized, photo details such as location removed). Add more, replace them (same names) or point `data/home.js` at your own files. Missing files show a grey placeholder that names the file to add. Do not use pictures containing customer or confidential information.
