# Employee Info practice files (SYNTHETIC)

Both files here are invented. All names, numbers, branches and policy text are fake and exist only to test the Employee Info page.

- `SYNTHETIC Phone Directory.xlsx`: same layouts as the real SBA phone directory (Name / Local / Direct blocks, a Branches sheet, a mobile-number list).
- `SYNTHETIC Code of Conduct.pdf`: same Article / Chapter / Section structure as a real code of conduct.

**Never upload the real phone directory or Code of Conduct to GitHub or the shared portal folder.** On the office PC, load them on the Employee Info page; they are remembered only in that browser.
