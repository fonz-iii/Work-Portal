How to use the Marketing Portal

A short, plain guide. If you only read one thing: open a module, add your file, click Create report, check it, then save.

  1. Step 1

    Choose your team

    On Home, click Product Management. The other teams are coming soon.

  2. Step 2

    Pick a report

    Click a card that says Ready to use. Cards that say Coming soon only describe what is planned.

  3. Step 3

    Add your file

    Click Choose file…, pick the Excel or PDF, then click Create report.

  4. Step 4

    Check, then save

    Read the draft on screen. If it looks right, save it as Excel, Word or PDF.

1Finding your way around

  • Top menu (white bar): Home, the four teams, Employee Info and How to use. The page you are on is highlighted.
  • “You are here” trail under the menu shows where you are, for example Home › Product Management › Benchmarking. Click any part to go back.
  • Back links on every report page take you to the list you came from.
  • Search box on Home: type a word such as “ranking” or “biller” and press Enter.
  • How to use button in the bottom-right corner brings you back to this guide from any page.

Lost? Click the Marketing Portal logo at the top left. It always takes you Home.

2Making a report

  1. Open Product Management and click the report you need.
  2. Under 1 · Choose your file, click Choose file… and pick the source file. The portal shows how many rows it read.
  3. Under 2 · Check the settings, confirm the quarter or date.
  4. Click Create report. If something is wrong with the file, a red box lists exactly what to fix.
  5. Under 3 · Review, then save, read the figures, chart and comments. Then click a Save button, or Print / PDF.

Want to practise first? Open Demo: Branch Deposits and use the sample file samples/demo-branch-deposits.xlsx. It is made-up data.

3Saving your files

  • Click Choose folder in the dark bar at the very top and pick a folder. Finished files then save straight into it.
  • The next time you open the portal, click Allow access once to keep using the same folder. This is a browser safety check.
  • If you do not choose a folder, files go to your Downloads folder.

4Fixing file errors

The portal checks every file before calculating anything. Common messages:

Message saysWhat to do
“is missing column(s): …”A column header is missing or spelled differently. Rename the header in Excel to match exactly, save, and choose the file again.
“must be a number on row(s) …”Those rows have text (such as “n/a”) where a number should be. Fix those cells and try again.
“not written like ‘Q3 2026’”The quarter is typed in a different format. Use Q, the number, a space and the year.
“No rows for …”The quarter you picked is not in the file. Pick a quarter listed in the message.
“Could not read …”The file may be open in Excel, password-protected or damaged. Close it in Excel and try again.

5Light and dark mode

Use the Light / Dark switch in the top-right corner of the dark bar. The portal remembers your choice. Reports, saved files and printouts always come out in light colors.

6Pictures and text on Home

  • Put picture files in the assets/images/ folder using the names shown on the grey placeholders (for example home-hero.jpg).
  • To change the headline or captions, open data/home.js in Notepad and edit the text between the quote marks.
  • Do not use pictures that show customer or confidential information.

7Privacy and sharing

  • The portal works offline. Files you choose are read on this computer and never leave it.
  • The portal is for the Marketing Group only. Do not share it or its outputs outside the group without approval.
  • Everything the portal produces is a draft. You review it and decide what gets sent.

8Suggesting a change

  1. Click Suggest a change in the bottom-right corner of any page.
  2. Pick what kind of change it is and describe it. The page you were on is filled in for you.
  3. Click Open email. Your email app (Outlook) opens with the message ready. Check it and click Send.

Email app didn't open? Click Copy text instead and paste it into a new email to the address shown in the form.

9Employee Info (Employee Directory and Code of Conduct)

  1. Open Employee Info in the top menu.
  2. The first time, click Choose file and pick the phone directory Excel (on the Employee Directory tab) or the Code of Conduct PDF (on the Code of Conduct tab). You can also drag the file onto the box.
  3. Type in the search box: a name (accents don't matter, so "munoz" finds "Muñoz"), a department, a branch, a local number or a word like "tardiness". To search only the directory, use the search box inside the Employee Directory tab. Click any number to copy it.
  4. When HR sends a newer file, click Replace with newer file.

Privacy: the files are read on this computer and remembered only in this browser. They are never uploaded and are not part of the portal folder. Do not put them in GitHub or the shared portal folder. On another computer, load them again. Remove from this PC deletes the saved copy.

The Code of Conduct view is a reading aid. The official version is the PDF from HR; each section shows its page number.

10QR Ph P2B Biller Directory (15th and month-end)

  1. Download the P2B Biller Masterlist .xlsx from the HUB. It is not attached to the advisory email.
  2. Open Product Management › RIB › QR Ph P2B Biller Directory. Add the masterlist, and if you have it, last period's masterlist.
  3. Click Create report. Check the counts (they should match the Excel Summary sheet) and compare the new, updated and total figures with the P2B Biller Advisory email, using the checklist on screen.
  4. If the advisory says otherwise, use Changes to the list to mark a biller new or updated, leave one out, or add one. Otherwise leave the list as the Excel says.
  5. Click Save Word directory (.docx). For a PDF, click PDF version and choose Save as PDF in the print window, or open the Word file and use Word's Save as PDF.

The file name follows the house format, e.g. List of QR Ph P2B list of billers_August 15, 2026.docx. Yellow rows are new billers; orange rows are updated biller details.

11Your portal folder (no more uploading)

Keep the files the portal needs in one folder on this computer. Each page then finds the newest file by itself; you only check it and click Create report.

  1. Click Choose folder in the top bar and pick a folder, for example Documents › SBA Portal Files. Click Allow when Chrome asks.
  2. The portal adds these folders inside it (and a READ ME file): 
    SBA Portal Files
  Employee Info       phone directory Excel + Code of Conduct PDF
  QR Ph Billers       P2B Biller Masterlist files (keep last period's too)
    Outputs           the directories and check sheets you save
  Industry Ranking
    2026-Q2           that quarter's four BSP thrift PDFs
    2026-Q3           newest folder = this quarter
    Outputs           the decks, reports and figures you save
  RIB Advisories      kept by the RIB Advisory Generator (don't edit by hand)
    Outputs           compilation Word files and backups
  3. Each project keeps its own Outputs folder, so a project's files and its finished reports stay together. Files in Outputs are never used as inputs. (An older shared Outputs folder at the top, if you have one, is no longer used; move or delete it as you like.)
  4. When a new file comes in, save it into its folder. Keep the date in the file name (for example P2B Biller Masterlist-As of 2026-09-30.xlsx); the newest date is used. For Industry Ranking, make a new quarter folder named like 2026-Q3.
  5. Open the page. The file boxes show From your portal folder and which file was picked. Click Choose file… if you want a different one.

Chrome asks again? After Chrome restarts it may ask to allow the folder. Click Allow (top bar or the yellow card on Home); choose Allow on every visit if offered. Nothing in the folder ever leaves this computer.

Want to try it first? Choose the practice folder samples/SBA Portal Files (practice). It holds only made-up or public files.

12RIB advisories

Open Product Management › RIB › RIB Advisory Generator. The bar at the top shows the three steps; click a step to open it.

  1. Write the advisory. Choose your name, add the email (file, pasted text, or type it in), pick the kind of advisory and check the details. Then copy the subject and the body into the RIB Inbox editor and click Save to tracker.
  2. Track posting. Each advisory has a card with four steps: Drafted › Posted on UAT (test site) › For Ms. Rocky’s approval › Posted on Prod (live site). When you finish a step, click the blue button on the card (for example I’ve posted it on UAT). The last step asks for the live date and a screenshot. Clicked by mistake? Use Undo last step.
  3. Compilation. Every advisory posted on Prod, newest first. Search, pick a kind or dates, then Download Word file or Print / Save as PDF.

First time: in Compilation, open Backup and restore › Restore from a backup file and choose the starter file RIB_advisories_starter_from_Sept_7_2026.json (keep it on your PC; it is not part of the portal). Advisories are kept in your portal folder under RIB Advisories; without a portal folder they stay in this browser until you choose one.

?Common questions

Do I need internet or to install anything?

No. Double-click index.html in the portal folder and it opens in Chrome or Edge.

A card says “Coming soon”. Can I use it?

Not yet. Click it to see what it will need and what it will produce. It opens once it is built and tested.

I put the files in the wrong box. Is that a problem?

No. For Industry Ranking the portal sorts the PDFs by their “As of” date: the latest is this quarter, the one before is the previous quarter. It tells you it did this under “Check before sending”.

Where did my saved file go?

Into the folder shown at the top (“Saving to …”). If no folder is shown, look in Downloads.

The comments say DRAFT thresholds. What does that mean?

The growth and decline bands used for the wording are placeholders until SBA approves them. The numbers themselves are calculated exactly from your file.

Can I break anything?

No. The portal never changes your source files and never sends anything. The worst case is a red box asking you to fix the file.

The phone directory shows a wrong or old number. Can I fix it here?

No. The page shows exactly what is in the Excel file. Ask the file owner to correct it, then load the newer file with Replace with newer file.

Do I still need to upload files?

Not if you use a portal folder (see Your portal folderRIB advisories). The Choose file buttons still work for a one-off file.

How do I suggest an improvement?

Use the Suggest a change button at the bottom right of any page. It prepares an email to the portal owner; you click Send.

Who do I ask for help?

The Product Management Officer who maintains the portal (Marketing Group).
